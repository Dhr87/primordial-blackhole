# My RPG
RPG de acción 3D en el navegador (Three.js + TypeScript). Ver `CLAUDE.md` para las reglas del estudio y `docs/ROADMAP.md` para las fases.

```bash
npm install
npx playwright install chromium
npm run dev
```
Luego abrir Claude Code en esta carpeta y pedir: "Lee CLAUDE.md y arranca la Fase 1 — Preproducción".
