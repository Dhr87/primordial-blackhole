# Roadmap

| Fase | Objetivo | Criterio de salida |
|---|---|---|
| 1. Preproducción | GDD, arquitectura, dirección artística, objetivos técnicos | Documentos revisados por Game Director + Technical Architect |
| 2. Prototipo jugable | Escenario, personaje, cámara, movimiento, combate básico, 1 enemigo, 1 habilidad, UI inicial, 1er sistema de progresión | Jugable de punta a punta; QA sin bloqueantes |
| 3. Vertical Slice | Sección pequeña con calidad representativa + audio, loot, guardado | Jueces ≥ 9 promedio, ninguna categoría crítica < 8 |
| 4. Producción | Regiones, enemigos, jefes, equipamiento, progresión | Contenido aprobado por jueces |
| 5. QA y optimización | Regresión, rendimiento, evaluación final | 60 FPS en hardware de referencia (ver [presupuestos y metodología](performance/budgets.md)), 0 errores de consola |
| 6. Release Candidate | Versión estable, documentada y reproducible | Checklist de release |

No se amplía el mundo hasta que la vertical slice pase las evaluaciones.
