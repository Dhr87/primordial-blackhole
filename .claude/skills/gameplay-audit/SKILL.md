# Gameplay audit
1. Ejecutar recorridos automatizados (Playwright) y, cuando se pueda, sesiones guiadas con checklist.
2. Evaluar 1–10: respuesta de controles, fluidez, sensación de combate, claridad, ritmo, profundidad, progresión, recompensas, coherencia.
3. Registrar momentos de frustración/confusión con evidencia (captura, log, video).
4. Decisión APROBADO/RECHAZADO + defectos; añadir fila a `docs/reports/AUDIT_LOG.md`.
Una mecánica que "funciona" pero no se siente bien no se aprueba.
